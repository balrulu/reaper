# BLT ReaScripts & JSFX

BLT ReaScripts is a collection of workflow tools for REAPER.
※β version

## Installation

1. Install [ReaPack](https://reapack.com/) if it is not already installed.
2. In REAPER, open **Extensions > ReaPack > Import repositories...**.
3. Paste the following repository URL:

   ```text
   https://github.com/balrulu/reaper/raw/main/index.xml
   ```

4. Synchronize ReaPack, open **Browse packages...**, and search for `BLT`.
5. Select the packages you want, choose **Install**, then click **Apply**.

## Requirements

- REAPER v7.62 以上（一部のスクリプトで必須）
- ReaPack
- 
  ・SWS 
  
  ・js_ReaScript API
  
  ・ReaImGui

## Updates

Use **Extensions > ReaPack > Synchronize packages** to check for new versions.
